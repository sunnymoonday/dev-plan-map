# 국토 개발계획 지도

정부·공공기관이 발표한 주요 개발계획(3기 신도시, 철도[전철·GTX·KTX], 신공항, 반도체 산단, 1기 신도시 정비 등 38건)의 위치를 지도에 표시하고, 클릭하면 사업 개요·진행 단계·추진 경과·관련 보도를 보여주는 단일 HTML 페이지입니다.

- 실행: `index.html`을 브라우저로 열면 됩니다(서버 불필요).
- 데이터: `index.html` 안의 `PROJECTS` 배열을 수정해 사업을 추가·변경합니다.
- 진행상태 기준일: 2026-11-13 (언론 보도 기준). 정확한 최신 현황은 각 항목의 관련 보도·기관 링크에서 확인하세요.
- 행정구역 경계: [southkorea-maps](https://github.com/southkorea/southkorea-maps) (KOSTAT 2013) 간략화.
